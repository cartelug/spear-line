## 5. Premium design upgrade

Reuse the existing warm industrial identity. Core palette: deep soil #15110C, umber #211A13, warm ivory #E9DFCE, muted olive #232A1D, selective gold #F2B65A. Reduce decorative overuse: premium means fewer stronger statements, not more glass/cards, animation and gradients everywhere.

Typography: use a properly web-licensed display and reading pair. Current MTN Brighter Sans/Sky Text files require licensing confirmation; follow ASSETS.md and do not assume bundling grants deployment rights.

Layout: disciplined 12-column composition, cinematic but grounded photography, paired dark/ivory editorial zones, high-quality category page composition, prominent whitespace, clear active/launch badges (functional status only), real process explanations, conversion-first buttons.
Motion: minimal scroll-linked parallax, masked reveal, purposeful transitions, preloader with reduced-motion alternative, nonintrusive header and responsive mobile menu. No movement that interferes with reading, accessibility or speed.
Accessibility: keyboard/focus, skip link, 200% zoom, adequate contrast, sensible alt text, 44px touch targets, safe-area support, no horizontal clipping.
Performance: AVIF/WebP responsive images, preload only above-the-fold hero, lazy load other imagery, stable layout, progressive enhancement. Maintain Lighthouse phone >90 as target.

Build company-sector pages and partner page, map and preserve legacy URLs, update navigation, breadcrumbs, metadata, structured data, sitemap and enquiry routing. Keep AI illustration notice where appropriate. No false Review, Product, LocalBusiness or inventory claims.

After code and asset integration, execute the repository's established build and regression commands:
- npm run critical
- npm run build
- npm run check
- npm test
- npm run test:e2e

Ensure public and root generated HTML mirror, pages-files manifest, robots rules and form behavior remain consistent. Test responsive 320–3440px, landscape, reduced motion, screen reader, keyboard, accessibility and mobile performance.
